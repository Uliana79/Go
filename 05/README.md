## Задание 5 — Максимум из N чисел

Пользователь сначала вводит количество чисел `N`, затем последовательно вводит `N` чисел.

Реализуйте программу, которая определяет максимальное и минимальное значения среди введённых чисел.

> **Отрабатываемые навыки:** цикл, пользовательский ввод, сравнение значений.
