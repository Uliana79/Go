## Задание 1 — Калькулятор с проверкой

Пользователь вводит два числа и одну из арифметических операций: `+`, `-`, `*` или `/`.

Реализуйте программу, которая выполняет выбранное вычисление. При делении предусмотрите проверку деления на ноль.

> **Отрабатываемые навыки:** `switch`, `if`, арифметические операции.
