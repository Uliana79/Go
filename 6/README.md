## Задание 6 — Количество положительных и отрицательных чисел

Введите `N` чисел.

Реализуйте программу, которая отдельно подсчитывает:

- количество положительных чисел;
- количество отрицательных чисел;
- количество нулей.

> **Отрабатываемые навыки:** цикл `for`, условные конструкции `if / else`, счётчики.
